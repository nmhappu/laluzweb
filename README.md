# laluzweb

Personal website for Aswalal A.C.: Prince Traders, LaluzGarage and CHRF Alappuzha.

Plain HTML/CSS/JS. No build step.

## Edit your details
Open `script.js` and fill in the `CONFIG` block at the top (phone, WhatsApp, address, Google Maps link, brands, photos).
Put photos in `assets/` and list them in `CONFIG.photos`.

## Preview locally
Open `index.html` in a browser.

## Publish (free)
GitHub repo → Settings → Pages → Source: deploy from branch → pick the branch, folder `/ (root)`.
